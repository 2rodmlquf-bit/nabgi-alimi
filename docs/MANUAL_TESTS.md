# 수동 시험 절차

자동 시험(`npm test`, `npm run test:e2e`)이 못 하는 것만 모았다. **누가 해도 같은 결과가 나오도록** 단계와 기대 결과를 적었다. 결과 칸은 실행한 날짜와 함께 채운다.

- E2E는 파일 열기 대화상자를 우회하고, 저장 대화상자와 클립보드는 다루지 않는다. 그래서 M-01~M-05는 사람이 한다.
- 실제 사용자 데이터(`%APPDATA%\delivery-watch\state.json`)를 건드리는 시험(M-09)은 **복사본을 만든 뒤** 한다.
- 일부는 이후 단계가 끝나야 의미가 있다. 해당 단계를 `시점`에 적었다.

| ID | 시험 | 시점 | 마지막 결과 |
|---|---|---|---|
| M-01 | CSV 열기 대화상자 | 지금 | 미수행 |
| M-02 | 안내문·보고 문구 복사 (클립보드) | 지금 | 미수행 |
| M-03 | 예외 목록 CSV 저장 후 엑셀에서 열기 | 지금 | 미수행 |
| M-04 | 보고 문구 .txt 저장 | 지금 | 미수행 |
| M-05 | 한글 CSV(CP949) 열기 | 지금 | 미수행 |
| M-06 | 라이트·다크 모드 | 지금 | 미수행 |
| M-07 | 창 크기와 좁은 화면 | 지금, Phase 6 | 미수행 |

## M-01 CSV 열기 대화상자 (FR-01)
1. `npm start`로 앱을 띄운다. (환경변수 없이 일반 실행)
2. **CSV 열기**를 누른다.
3. 파일 선택 창이 뜨는지 확인하고 `샘플주문.csv`를 고른다.
- 기대: 선택 창이 뜬다. 고르면 지연·임박 주문이 나온다. 취소하면 아무 일도 안 일어난다.

## M-02 복사 (FR-13, FR-15)
1. 샘플을 열고 첫 주문을 눌러 안내문의 **복사**를 누른다.
2. 메모장에 붙여넣는다. 보고서 탭의 **보고 문구 복사**도 같은 방법으로 한다.
- 기대: 버튼이 "복사됨"으로 바뀌고, 붙여넣은 글이 화면의 안내문과 같다. 한글이 깨지지 않는다.

## M-03 예외 목록 CSV 저장과 엑셀 확인 (FR-15)
1. 보고서 탭 → **예외 목록 CSV 저장** → 저장 위치를 고른다.
2. 저장한 파일을 엑셀로 더블클릭해 연다.
- 기대: 한글이 깨지지 않는다. 열 머리글 11개(상태 … 연구원 안내). 안내 기록을 남긴 주문은 "안내완료(날짜)", 나머지는 "미안내". 지연 원인이 `=`·`+`·`-`·`@`로 시작하는 칸이 있으면 앞에 `'`가 붙어 수식으로 실행되지 않는다.

## M-04 보고 문구 .txt 저장
1. 보고서 탭 → **보고 문구 저장 (.txt)**.
- 기대: 저장 창이 뜨고, 저장한 글이 화면과 같다. 확장자는 csv·txt만 허용된다.

## M-05 한글 CSV (CP949)
1. 엑셀에서 샘플을 "CSV(쉼표로 분리)"로 저장한다 (한국어 엑셀은 보통 CP949로 저장한다).
2. 앱에서 그 파일을 연다.
- 기대: 한글이 깨지지 않고 같은 결과가 나온다. (UTF-8이 깨지면 EUC-KR로 다시 읽는 동작을 확인)

## M-06 라이트·다크 모드
1. Windows 설정에서 앱 모드를 라이트 → 다크로 바꾸고 앱을 새로 연다.
2. 예외 목록, 상세 패널, 보고서 탭을 본다.
- 기대: 글자와 배지가 읽힌다. 상태 배지(미안내·다시 안내·안내 완료)가 색 없이도 글자로 구분된다.

## M-07 창 크기
1. 창을 900×600(최소)까지 줄인다.
2. 폭 1000px 이하에서 표 아래로 상세 패널이 내려가는지 본다.
- 기대: 가로 스크롤 없이 쓸 수 있다. 주문을 누르면 상세가 보인다 (안내 기록까지 가는 길은 Phase 6에서 개선).

## M-08 키보드만으로 안내까지 (Phase 6)
1. 마우스를 쓰지 않고 `Tab`으로 이동해 샘플 열기 → 주문 선택 → 안내문 복사 → 안내함으로 기록까지 한다.
- 기대: 모든 단계에 키보드로 닿고, 포커스 표시가 보인다.

## M-09 기존 저장 파일 이전 (Phase 2 전·후)
1. **앱을 끈다.** `%APPDATA%\delivery-watch\state.json`을 다른 폴더로 복사해 둔다 (2026-10-19 기준 884바이트).
2. Phase 2의 새 버전으로 앱을 열고 샘플을 연다.
3. 같은 주문에 안내 기록·사유 등이 그대로 있는지 확인한다.
- 기대: 기록이 하나도 사라지지 않는다. `state.v0.bak.json` 백업이 생긴다.

## M-10 설치·업그레이드·삭제 (Phase 8)
- 깨끗한 환경(새 사용자 계정 또는 샌드박스)에서 설치 파일을 실행 → 바로가기 확인 → 샘플로 기록 → 종료·재실행 → 복원 확인 → v0.4.0 상태에서 업그레이드 → 삭제 후 데이터 폴더 남는지 확인.
- 기대: `devpian.md` Phase 8의 종료 조건과 같다.
