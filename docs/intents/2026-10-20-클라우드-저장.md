# Intent (완료): 클라우드 저장 (연습용 Supabase)

> 끝난 작업의 의도 기록. 새 작업의 Intent는 저장소 루트의 `Intent.md`에 쓴다. 상태: **구현·시험 완료, v0.6.0 릴리스** (2026-10-20)

## 1. 문제
기록(안내·메모·연락·설정)이 이 컴퓨터의 파일 하나에만 있어 컴퓨터가 바뀌거나 파일이 망가지면 잃는다. "실제 데이터를 데이터베이스로" 옮기고 싶다는 요구가 있었다.

## 2. 기대 결과
- 기록이 서버(Supabase)에도 사본으로 남고, 필요할 때 복원한다. 켜기 전과 끄면 지금과 100% 같다.
- 인터넷이 끊겨도 기록은 막히지 않는다. 끊김·실패는 이유와 다음 행동을 알려 준다.
- 이 컴퓨터는 처음 로그인한 계정에만 묶인다.

## 3. 영향 범위
사용자: 담당자 한 명. 시스템: 로컬 저장 형식 v2(`src/store`), 올리기·복원·로그인(`src/sync`, 메인 프로세스), 클라우드 패널 화면(SY-11-M, AU-11-M, SY-21-A, SY-31-M), Supabase 연습용 프로젝트(표 8개, RLS).

## 4. 제약
예산 0원(무료 플랜), 가상 데이터만, `service_role` 금지, 연습용 프로젝트만(업무용은 보안 승인 뒤), 로컬이 기준(ADR-0002), 쌓는 기록은 지우지 않음.

## 5. 열린 질문 → 결과
| 질문 | 결과 |
|---|---|
| 올리기 방식(대기열 vs 장부 비교) | 장부 비교로 결정 (ADR-0006) |
| 프로젝트 분리 | 연습용/업무용 2개 (ADR-0003) |
| 로그인 | 선택, 첫 로그인 계정에 묶음 (ADR-0005) |
| legacy 기록 | DB로 옮김, 저장 형식 v2 (ADR-0001) |
| 주문번호 유일성 | 가정으로 두고 겹침 경고 추가 (ADR-0004) |
| 다기기 병합 | 범위 밖 |
