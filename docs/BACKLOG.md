## 새로 발견한 것 (Phase 0)

| # | 내용 | 다룰 곳 |
|---|---|---|
| N-1 | npm 11이 `electron-winstaller` 설치 스크립트가 `allowScripts`에 없다고 경고한다. 새 PC에서 `npm ci`와 `npm run dist`가 되는지 확인해야 한다 | Phase 8 |
| N-2 | 이 앱의 실제 데이터 폴더 이름은 `%APPDATA%\delivery-watch` (패키지 이름 기준, 제품 이름 "납기 알리미"가 아님). 문서·설치 안내에 정확히 적어야 한다 | Phase 8 문서 |
