납기 알리미 발표 가이드

무엇을 보여 주고, 어느 화면을 어떻게 켜고, 무슨 말을 할지 순서대로 적었어요. 시연은 약 7분 기준이고, 시간이 짧으면 표시된 곳만 하면 돼요.

발표 전 준비

체크하면 줄이 그어져요(이 브라우저에만 기억돼요).

한 줄 메시지와 세 가지 포인트

처음과 마지막에 같은 말을 해요.

"납기가 늦어질 때, 연구원에게 먼저 알리고 공급사 회신까지 챙겨 주는 바탕화면 프로그램입니다."

1. 문제

누구에게 알렸는지, 오늘 어느 공급사에 연락해야 하는지가 엑셀·메일·메신저에 흩어져 자주 놓쳐요.

2. 해결

예외 주문만 골라 보여 주고, 안내 기록을 남기고, 공급사가 약속한 날이 지나면 "회신 늦음"으로 알려요.

3. 만든 방식

문서를 먼저 쓰고, 코드는 그다음. AI에게 규칙을 정해 주고 시켰고, 시험과 QA 기록을 남겼어요.

예상 질문과 답

눌러서 펼쳐요.

왜 메시지를 앱이 대신 보내 주지 않나요?

잘못된 내용이 연구원이나 공급사에게 나가면 되돌릴 수 없어요. 앱은 글을 만들어 주고 복사만 해요. 보내는 건 사람이고, 보낸 뒤 "안내함으로 기록"을 눌러요.

실제 업무 데이터로 해 봤나요?

아니요. 모두 가상 데이터예요. 그래서 회사 시스템 엑셀처럼 보이게 따로 만든 가상 엑셀(86건)을 앱에 열어 봤어요. 실제 데이터는 쓰지 않았고, 실제 업무에 쓰려면 사람이 한 번 더 확인해야 해요.

가장 어려웠던 점은 무엇인가요?

가상 엑셀을 만들었는데 실제 엑셀에서는 열리지 않았어요. 앱 안의 시험은 모두 통과했는데, 앱의 읽기가 관대해서 잘못된 파일도 읽었기 때문이에요. 구조를 고치고 구조를 확인하는 시험을 추가했어요. 시험이 통과해도 실제 환경에서 확인해야 한다는 걸 배웠어요.

"회신 늦음"은 어떻게 판단하나요?

가장 최근 회신의 약속일이 기준일보다 지났을 때(당일은 아님)예요. 저장하지 않고 매번 계산해요. 그날 그 공급사에 이미 연락했다면 조용히 있고, 다음 날 다시 알려요.

엑셀 열 이름이 다르거나 날짜가 이상하면요?

열 이름은 자동으로 연결하고, 안 맞으면 "열 매핑 보기"에서 직접 고칠 수 있어요. 읽을 수 없는 날짜("미정", "10월 말")는 지어내지 않고 '확인 필요'로 따로 보여 줘요.

서버에 데이터가 올라가나요? 보안은요?

기본은 이 컴퓨터에만 저장해요. 클라우드 저장은 설정에서 켜야만 되고, 연습용 서버에 가상 데이터만 올려요. 본인 행만 보이도록 서버 규칙(RLS)을 걸었고 비밀번호는 저장하지 않아요. 앱 안에는 서버 주소나 키가 들어 있지 않아요.

AI를 어떻게 썼나요? 직접 만든 건가요?

AI가 코드를 쓰고 저는 무엇을 만들지, 어떤 규칙으로 만들지를 정하고 승인했어요. 문제 정의·화면 구조·사용자 여정·요구사항 문서를 먼저 쓰고, 애매한 건 인터뷰로 정했고, 되돌리기 어려운 결정은 결정 기록(ADR)으로 남겼어요.

아직 부족한 점은 무엇인가요?

실제 데이터로 쓰지 않았고, 사람이 눈으로 확인해야 하는 QA 항목(글이 읽기 편한지, 깨끗한 컴퓨터 설치 등)이 남아 있어요. 클라우드는 연습용 서버예요. 다음에는 실제 사용자 한두 명에게 써 보게 하는 것이 먼저예요.

문제가 생기면

앱이 안 켜져요

작업 표시줄에 이미 켜진 창이 있는지 먼저 봐요(중복 실행은 새 창이 안 떠요). 그래도 안 되면 소개 페이지의 화면 캡처로 설명하고, 그 사이에 납기알리미-앱실행.bat을 다시 눌러요.

엑셀이 안 열려요

그 자리에서 샘플 불러오기로 넘어가요. 샘플은 앱 안에 들어 있어서 파일이 필요 없어요.

인터넷이 안 돼요

앱은 인터넷 없이도 돼요. 소개 페이지만 안 열리니, 미리 열어 둔 탭을 쓰거나 캡처로 설명해요.

숫자가 달라요

기준일이 오늘 날짜로 되어 있는지 봐요. 2026-10-12로 바꾸면 돌아와요. 샘플은 자동으로 맞춰져요.

클라우드 저장은 시연하지 않는 걸 추천해요. 연습용 서버와 로그인이 필요해서 발표 중 실패할 위험이 커요. 소개 페이지의 클라우드 캡처와 설계 설명으로 대신해요.

이 가이드의 화면 이름과 숫자는 앱 v0.7.1과 소개 페이지 기준이에요. 시연 순서의 클릭 경로와 숫자(15건, 회신 늦음 3일째, 메일 4→3)는 자동 시험과 직접 실행으로 확인했어요. 발표용 실행 파일을 켜는 것까지는 확인했지만, 이 순서대로 처음부터 끝까지 사람이 따라 해 본 리허설은 아직 하지 못했어요.
