납기 알리미

발주한 물건이 늦어질 때, 연구원에게 먼저 알리고 공급사에게는 어떤 순서로 연락할지 정리해 주는 바탕화면 프로그램입니다. 물류 담당자로 일하던 경험에서 출발했습니다.

설치 파일 받기 (Windows, 107MB) 릴리스 노트 소스 코드 (GitHub)

어떤 문제를 풀려고 했나요

납기 관리는 "알고 있는 것"과 "알려야 하는 것"이 엑셀, 메일, 메신저에 흩어져 있어서 자주 놓칩니다.

누구에게 알렸는지 기억이 안 남

지연된 주문을 연구원에게 알렸는지, 언제 어떤 방법으로 알렸는지 기록이 없어 같은 말을 두 번 하거나 아예 빠뜨립니다.

오늘 연락할 곳이 한눈에 안 보임

공급사별로 연락한 날과 답이 없는 횟수를 기억에 의존합니다. 답 없는 공급사는 방법을 바꿔야 하는데 시점을 놓칩니다.

전체 주문이 아니라 "예외"만 보고 싶음

주문 수백 건 중 임박·지연·납기 불명인 것만 골라 보여 주면 확인 시간이 크게 줄어듭니다.

이렇게 일합니다

화면 위쪽 메뉴도 이 순서대로 놓았습니다. 자주 하는 일은 왼쪽, 가끔 바꾸는 설정은 오른쪽입니다.

  1. 홈에서 오늘 할 일 보기 — 파일을 열면 맨 앞 "홈" 탭에 안내할 것, 회신 늦음, 오늘 연락할 곳이 건수와 함께 나옵니다.
  2. 주문 목록 열기 — 엑셀(.xlsx)이나 CSV 파일을 그대로 엽니다. 열 이름이 달라도 자동으로 연결합니다.
  3. 예외 목록 보기 — 지연·임박·납기를 읽을 수 없는 주문만 표에 나옵니다.
  4. 연구원에게 안내하고 기록 — 안내문을 만들어 복사하고 "안내함으로 기록"을 누르면 언제 어떤 방법으로 알렸는지 남습니다. 새 소식 없이 7일이 지나면 "다시 안내"로 알려 줍니다.
  5. 공급사 회신 기록 — 회신 받은 날과 약속일을 적어 두면 "회신 늦음 N일째"를 계산해 알려 주고, 연구원에게 보낼 답변 초안(이메일·전화 요점)을 만들어 줍니다. 이메일에서 회신 기록을 제안하지만 누를 때만 기록합니다.
  6. 오늘 연락할 곳 확인 — 공급사별로 연락 기록과 무응답 횟수를 보고 다음 방법(전화 → 상급자 경유 → 대체 공급사 검토)을 제안합니다.
  7. 분석과 보고서 — 지연 원인 비중을 보고 보고서를 내려받습니다.
