# Supabase DB QA 환경

연습용 프로젝트 `nabgi-practice`의 데이터베이스가 **실제로** 규칙대로 동작하는지 확인하는 환경이다. 시험 계정 2개(A, B)와 가상 데이터만 쓴다. 프로젝트 주소·키·시험 계정 정보는 이 폴더의 `*.local.*` 파일에만 있고 **저장소에는 올라가지 않는다**(`.gitignore`).

## 지금 상태 (2026-10-20)

| 항목 | 상태 |
|---|---|
| 자동 시험 `node supabase/qa/db-tests.js` | **47/47 통과** (실제 Supabase에 로그인해서 REST API로 확인) |
| QA 화면 시나리오 14개 | A·B 두 계정 모두 **14/14 기대대로** (브라우저에서 자동 실행으로 확인) |
| 시험 계정 | A, B 만들어 둠 (이메일 `qa-a@nabgi-qa.test`, `qa-b@nabgi-qa.test`). 비밀번호는 `qa-users.local.json` |
| 시험 데이터 | A: 안내 기록 8(삭제 표시 없는 것 6), 빠른 메모 3, 주문 메타 3, 대체품 2, 분납 2, 공급사 연락 4, 연락함 표시 2, 설정 1 / B: 안내 기록 3, 빠른 메모 1, 설정 1 |

## QA 화면 열기

```bash
node supabase/qa/serve.js
```

브라우저에서 **http://localhost:5173** 을 연다. 이 컴퓨터에서만 열린다(같은 네트워크의 다른 컴퓨터는 접속 불가). 끄려면 `Ctrl+C`.

화면은 4부분이다: ① 로그인(A/B 버튼) ② 내 데이터 보기(표 8개) ③ 직접 해 보기 14개 시나리오 ④ 요청 기록. 시나리오마다 `[실행]`을 누르면 결과가 "기대대로"인지 자동 판정하고, 직접 눈으로 확인했으면 "내가 확인함"에 체크한다.

## QA 체크리스트 (직접 해 보세요)

로그인 계정: A와 B를 번갈아 쓴다. 결과는 화면의 ✔/✘와 아래 "기대"를 비교한다.

| # | 하는 일 | 기대 결과 | 실제 | 확인 |
|---|---|---|---|---|
| 1 | 로그아웃 상태에서 ②의 아무 표를 연다 | "거부됨"이 나온다 (로그인 없이는 읽을 수 없음) | | ☐ |

| 3 | A → ② 빠른 메모, 주문 메타, 대체품, 분납, 공급사 연락, 연락함 표시, 설정 | 각각 3 / 3 / 2 / 2 / 4 / 2 / 1행 (아래 "시험 데이터" 표) | | ☐ |

## 명령 모음

| 하고 싶은 일 | 명령 |
|---|---|
| 자동 시험 47개 | `node supabase/qa/db-tests.js` |
| 시험 데이터를 처음 상태로 되돌림 (설정·주문 메타도 덮어씀) | `node supabase/qa/seed.js` |
| 시험이 남긴 행 지우기 | `cleanup.sql`의 [1]을 Supabase SQL Editor에서 실행하거나 Claude에게 "QA 정리해줘" |
| QA를 다 끝냈을 때 시험 계정 지우기 | `cleanup.sql`의 [2] (실제 로그인 계정을 만든 뒤에) |
| 새 환경에서 시험 계정 만들기 | `node supabase/qa/make-users.js` → 만들어진 `qa-users.local.sql`을 SQL Editor에서 실행 |

자동 시험(`db-tests.js`)은 시험 행을 만들고 끝에 삭제 표시를 붙인다. DB가 지우기를 막으므로 행은 남는다. 여러 번 돌리면 쌓이니 가끔 `cleanup.sql` [1]로 지운다. 화면은 삭제 표시 행을 기본으로 숨긴다.

## 이 환경이 보장하는 것과 못 하는 것

보장(자동 시험과 화면 시나리오로 확인): 로그인하지 않은 접근 거부, 본인 행만 읽기·쓰기, 남의 이름으로 쓰기 거부, 쌓는 기록의 수정·삭제 거부와 삭제 표시만 허용, 값 규칙(채널·상태·글자 수·날짜), 같은 id 두 번 올리기 멱등, 현재 값 표의 최신 우선, 한글·이모지·줄바꿈 보존, 500건 대량 입출력.

못 하는 것: 이 환경은 **데이터베이스**만 확인한다. 앱(Electron)에서 올리기·복원이 되는지는 앱 쪽 코드가 생긴 뒤에 확인한다(아직 없음). 로그인 화면의 가입 닫기·이메일 확인 끄기는 Supabase 화면의 설정이라 이 환경에서 시험하지 않았다(`supabase/README.md`의 "화면에서 직접 해야 하는 것").
