납기 알리미 · DB QA 화면

Supabase 연습용 데이터베이스가 제대로 작동하는지 직접 눌러 보는 화면이에요. 시험 계정(A, B)과 가상 데이터만 쓰세요. 이 화면은 내 컴퓨터에서만 열리고, 비밀번호는 어디에도 보내거나 저장하지 않아요(로그인할 때 Supabase로만 보내요).

설정 파일(qa-config.local.js)을 못 찾았어요. supabase/qa/README.md의 준비 순서를 보세요.

① 로그인

"A로 로그인"과 "B로 로그인"은 시험 계정으로 바로 들어가요(비밀번호를 칠 필요 없음). 다른 계정으로 해 보려면 아래에 직접 입력하세요.

로그아웃 상태
직접 입력해서 로그인

② 내 데이터 보기

로그인한 계정이 볼 수 있는 행만 나와요. 계정 A와 B로 번갈아 로그인해서 서로의 데이터가 안 보이는지 확인해 보세요. 줄이 그어진 행은 "삭제 표시"가 된 기록이에요.

③ 직접 해 보기 (시나리오)

[실행]을 누르면 결과가 "기대대로"인지 자동으로 판정해요. 눈으로 확인했으면 "내가 확인함"에 체크하세요(이 브라우저에 기억돼요). 일부러 거부돼야 하는 시도도 있어요. 거부되면 성공이에요.

④ 요청 기록 (고급)

이 화면이 Supabase에 보낸 요청과 응답이에요(최근 30건). 비밀번호와 로그인 증표는 보여 주지 않아요.
